# UnlockYour100

> UnlockYour100 is a Flutter-based Android application that displays educational questions on the lock screen to promote effortless spaced repetition learning throughout the day.

## Motivation

Traditional study methods like cramming are often ineffective, while spaced repetition is a proven strategy for retaining information long-term. However, implementing it requires consistent effort, which many users struggle with. UnlockYour100 leverages frequent phone usage—an average of 96 times a day—to seamlessly integrate spaced repetition into daily routines. By presenting questions on the lock screen, the app encourages users to study incrementally and efficiently without interrupting their regular activities.

## Core Features
* [ ] Allow a user to create questions manually or with AI assistance
* [ ] Display a random user-defined-question every time the lock screen is opened.
* [ ] Organizes a user's questions by sets and toggle their availability
* [ ] Use AI to generate sets of questions wholesale based on user-defined-topics or from files of course material 

## Complementary Features
* [ ] Automatically generate incorrect answers for user-defined multiple-choice questions.
* [ ] Show detailed usage statistics to track learning progress.
* [ ] Support for both multiple-choice questions and for numerical-answer questions.
