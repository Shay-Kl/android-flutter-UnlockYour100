# UnlockYour100


> UnlockYour100 is a Flutter-based Android application that allows students studying for tests to build ai gnerated quizzes to promote effortless spaced repetition learning.


## Motivation

Traditional study methods like cramming are often ineffective, while spaced repetition is a proven strategy for retaining information long-term. However, implementing it requires consistent effort, which many students struggle with. UnlockYour100 helps students prepare for exams by providing a structured way to review material regularly. By presenting questions within the app, it encourages consistent study habits and reinforces knowledge retention over time.

## Core Features

* [ ] Allow a user to create questions manually or with AI assistance
* [ ] Display a series of questions from currently active sets in the quiz screen.
* [ ] Organizes a user's questions by sets and toggle their availability
* [ ] Use AI to generate sets of questions wholesale based on user-defined topics or from files of course material


## Complementary Features

* [ ] Automatically generate incorrect answers for user-defined multiple-choice questions.
* [ ] Show detailed usage statistics to track learning progress.
